Basics

Popularity is stored on the record, but the shop's “Popularity” sort does not read it — products.js ranks by average star rating from product_reviews, with review count breaking ties. Editing this changes the stored number, not the shop's ordering.

The switch is the field the shop reads — off leaves the product listed with a “Sold Out” badge and Add to Cart disabled. Leave the count empty to not track units for this product; empty is not the same as zero.

Price above stays the product’s normal price — switching the sale off brings it straight back. The shop shows the old price struck through beside the new one.

Images

The first image is the one used as the thumbnail. Each row previews live, so a URL that cannot load shows up here rather than on the shop. Upload a file or paste a URL — both end up as a URL on the product.

Attributes

Picker options on the product page — color, size, and anything else you add. Separate the values with commas.

Specs

The spec table on the product page — Material, Weight, Warranty, Origin.
